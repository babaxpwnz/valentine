# code_to_phone

Одностраничная валентинка: вопрос «Будешь ли моей Валентинкой?», кнопка «Нет», которая
убегает от курсора, летящие сердечки и GIF после согласия.

## Структура

```
index.html      разметка страницы
css/style.css   стили, анимации сердечек и кнопок
js/main.js      убегающая кнопка, сердечки, обработка согласия
```

## Запуск

Зависимостей и сборки нет — достаточно открыть `index.html` в браузере.
Локальный сервер (нужен, чтобы корректно грузился встроенный GIF):

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000
